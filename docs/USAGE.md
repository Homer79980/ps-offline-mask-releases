## 单图抠图

1. 在 Photoshop 中选择一个普通像素图层。插件打开或图层选择变化时会自动读取；同一图层的像素内容变化后，可点“刷新”重新读取。
2. 点击“一键抠图”。本地算法只更新插件内的临时结果，不会立即改动图层。
3. 在缩略图检查彩色抠图效果。点击右上角放大图标或“精修”都会打开同一个抠图工作台。
4. 需要调整边缘时进入工作台，在右侧属性中操作。预览会实时更新，无需再次点击“一键抠图”。
5. 确认后点击“应用”。本地算法有可靠前景色修正时会创建新的带蒙版像素图层并保留源图；仅有 Alpha 时写入可撤销蒙版。

## 统一抠图工作台

工作台沿用 Photoshop 的布局习惯，但本版精修是“结果 + 参数”工作区，不提供手工像素绘制：

| 操作 | 输入 |
|---|---|
| 预览结果 | 右侧“查看”选择透明/纯色/自定义背景或黑白蒙版 |
| 缩放 | 左侧缩放工具，或底部 `-`/`+`/滑杆 |
| 平移 | 按住空格并用左键拖动，或选择抓手工具 |
| 调整边缘 | 右侧“边缘”参数；柔边与硬边互斥 |
| 计算/应用 | 底部“计算”生成候选，“应用”写回蒙版 |
| 适合窗口 | 底部“适合窗口” |

未知、保留、删除画笔、画笔光标、颜色拖拽填充和手工 Trimap 已移除。画布点击不会改变蒙版，只改变视口。取消工作台会恢复打开工作台时的结果。

## 查看与边缘调整

“查看”支持：

- 抠图效果：透明、白色、黑色、灰色、自定义背景
- 黑白蒙版
- 计算前后对比

边缘参数作用于不可变的基础 Alpha：

- **边缘收缩/扩张**：负值去白边或色边，正值补回被吃掉的边缘。
- **柔边模式 / 抗锯齿柔化**：向主体内部建立平滑过渡，不把明确背景重新变成半透明。
- **硬边模式 / 硬边阈值**：用于必须保持像素硬边的 UI 资产。柔边与硬边是两种互斥策略，切换模式后只显示当前有效的控制项。
- **去白边 / 色边**：切换是否使用校正后的前景 RGB，便于对比背景污染是否被去除。
- **反相蒙版**：交换保留和删除。

调整参数时，黑白蒙版和彩色抠图预览会同步重建。彩色预览优先使用算法修正后的前景 RGB，便于在深浅背景上直接观察白边、色边和半透明过渡。大图会先显示最长边 1024 像素的交互预览，并提示正在生成全分辨率结果；全分辨率结算完成前“应用”保持禁用。

### 屏幕色与 Keylight 风格参数

在“查看”属性中，背景色不是装饰文本：色块显示当前合成背景，点击色块可打开系统颜色选择器，旁边的十六进制框可直接输入 `#RRGGBB`。点击“吸取”后，预览画布会显示吸管图标；点击一次替换屏幕色，按住 Shift 点击则把新颜色加入屏幕色样本（最多 8 个）。这些样本会送入本地屏幕色求解器，用于处理渐变、压缩噪声和多色背景。

“屏幕抠像（Keylight 风格）”参数用于本地 Alpha 和前景去溢色后处理：屏幕增益/平衡控制 Alpha 对比，去溢色偏差与溢色抑制降低背景色污染，黑场/白场裁切控制透明与不透明端点。它们借鉴 Keylight 1.2 的工作语义，但不是 Adobe 专有插件的二进制复刻；参数改动会实时同步黑白蒙版和彩色结果，点击“应用”前不会写回源图层。

## 图层批量

1. 在 Photoshop 图层面板中多选像素图层。
2. 点击“图层批量”。
3. 插件按图层顺序串行处理并应用结果。

文字、组、智能对象、背景层和完全锁定层会跳过并报告原因。单层失败会尝试恢复该层后继续；恢复失败、文档切换、选择变化或图层边界变化会停止后续写入。

## 文件夹批量

1. 点击“文件夹批量”。
2. 选择源目录和输出目录；授权会由 UXP 保存为持久令牌，不在配置中记录本机路径。
3. 需要处理子目录时勾选“包含子文件夹并保留目录结构”。
4. 选择边缘预设，点击“开始”。
5. 查看成功、失败、跳过数量和当前文件；需要停止时点击“停止”，当前文件安全结束后不再启动下一张。

支持 PNG/JPG/JPEG/WebP。输出是透明 PNG，默认文件名为 `原名_cutout.png`；重名时自动使用 `_2`、`_3` 等编号，绝不覆盖现有文件。同一目录作为源和输出时会跳过插件先前生成的 `_cutout` 文件。已经在 Photoshop 中打开的源文件不会被批处理。

文件夹批量会为每张图片临时打开文档、读取合成像素、运行本地算法、导出透明 PNG、无保存关闭源文件，再恢复批处理前的活动文档。单张失败不会影响后续图片；失败占位文件会被清理。完成状态只显示在批量窗口中，不会在输出目录生成 JSON 或其它旁车报告。

## 本地算法适用范围

最适合：透明 PNG、纯色/近纯色背景、硬边图标、游戏/UI 素材、高对比商品图。

需要精修或视觉模型：场景/渐变背景、主体与背景颜色高度接近、发丝、玻璃/烟雾等半透明材质、同色语义细节。纯 RGB 信息不足时，本地算法会以 `non-uniform-background-border`、`ambiguous-foreground-background` 或相关风险失败关闭，不会承诺任何图片都自动抠净。

## 可选 AI 视觉模型

默认预览包未配置 AI，也不会上传图层。用户在同一插件的 AI 设置分页保存视觉模型后，一键流程仍先使用本地算法；复杂或低置信度图像才自动调用视觉服务。API 必须返回结构化 Alpha/区域 JSON，候选会经过本地边缘参数处理后再进入统一预览和应用路径。无 API、超时或非法响应会保留候选并阻止应用。

## 安全与故障反馈

- “撤销”丢弃插件内未应用结果，不修改 Photoshop 图层。
- 计算结果使用请求版本保护，过期异步结果不会覆盖新结果。
- 应用失败时保留工作区状态，便于继续修正或重新尝试。
- 若 Photoshop 菜单出现两个插件入口，说明旧实例仍在加载；Stop、移除旧实例并从新目录重新 Add/Load。
- 真实宿主故障请保留完整状态栏文字、Photoshop 版本、操作步骤和截图；不要只截“失败”二字。
