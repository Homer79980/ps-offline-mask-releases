## 单图抠图

1. 在 Photoshop 中选择一个普通像素图层。插件打开或图层选择变化时会自动读取；同一图层的像素内容变化后，可点“刷新”重新读取。
2. 点击“一键抠图”。本地算法只更新插件内的临时结果，不会立即改动图层。
3. 在缩略图检查彩色抠图效果。点击右上角放大图标或“精修”都会打开同一个抠图工作台。
4. 在主面板或工作台右侧调整边缘参数。预览会实时更新，无需再次点击“一键抠图”。
5. 确认后点击“应用”。本地算法有可靠前景色修正时会创建新的带蒙版像素图层并保留源图；仅有 Alpha 时写入可撤销蒙版。

## 统一抠图工作台

工作台沿用 Photoshop 的操作习惯：

| 操作 | 输入 |
|---|---|
| 选择未知/保留/删除 | 左侧工具按钮 |
| 绘制 Trimap | 画布中按住左键拖动 |
| 缩放 | 鼠标滚轮，或底部 `-`/`+`/滑杆 |
| 平移 | 按住空格并用左键拖动，或选择抓手工具 |
| 调整笔刷直径 | `[` / `]` |
| 调整笔刷柔软度 | `Shift+[` / `Shift+]` |
| 抓手/缩放工具 | `H` / `Z` |
| 撤销/重做 | `Ctrl+Z` / `Ctrl+Shift+Z`，macOS 使用 `Cmd` |
| 适合窗口 | 底部“适合窗口” |

未知、保留、删除分别为蓝、绿、红半透明画笔。画布上的双圆环光标实时表示笔刷外径和柔软内核；每次按下到释放记为一笔历史。

“重置标记”恢复自动初稿但保留当前边缘参数；“重置全部”恢复打开工作区时的完整快照。绘制过程中按 `Esc` 只取消尚未释放的当前笔迹。

绘制后“重新计算”才会启用新的蒙版，“应用”在重算前保持禁用。这样可以避免把旧蒙版误应用到已经修改的 Trimap。取消工作台会恢复打开工作台时的标记和结果。

## 查看与边缘调整

“查看”支持：

- 抠图效果：透明、白色、黑色、灰色、自定义背景
- 黑白蒙版
- 原图加 Trimap 标记
- 计算前后对比

边缘参数作用于不可变的基础 Alpha：

- **边缘收缩/扩张**：负值去白边或色边，正值补回被吃掉的边缘。
- **抗锯齿柔化**：向主体内部建立平滑过渡，不把明确背景重新变成半透明。
- **硬边阈值**：用于必须保持像素硬边的 UI 资产；与柔化互斥。
- **反相蒙版**：交换保留和删除。

调整参数时，黑白蒙版和彩色抠图预览会同步重建。彩色预览优先使用算法修正后的前景 RGB，便于在深浅背景上直接观察白边、色边和半透明过渡。大图会先显示最长边 1024 像素的交互预览，并提示正在生成全分辨率结果；全分辨率结算完成前“应用”保持禁用。

## 图层批量

1. 在 Photoshop 图层面板中多选像素图层。
2. 点击“图层批量”。
3. 插件按图层顺序串行处理并应用结果。

文字、组、智能对象、背景层和完全锁定层会跳过并报告原因。单层失败会尝试恢复该层后继续；恢复失败、文档切换、选择变化或图层边界变化会停止后续写入。

## 文件夹批量

1. 点击“文件夹批量”。
2. 选择源目录和输出目录；授权会由 UXP 保存为持久令牌，不在配置中记录本机路径。
3. 需要处理子目录时勾选“包含子文件夹并保留目录结构”。
4. 选择边缘预设，点击“开始”。
5. 查看成功、失败、跳过数量和当前文件；需要停止时点击“停止”，当前文件安全结束后不再启动下一张。

支持 PNG/JPG/JPEG/WebP。输出是透明 PNG，默认文件名为 `原名_cutout.png`；重名时自动使用 `_2`、`_3` 等编号，绝不覆盖现有文件。同一目录作为源和输出时会跳过插件先前生成的 `_cutout` 文件。已经在 Photoshop 中打开的源文件不会被批处理。

文件夹批量会为每张图片临时打开文档、读取合成像素、运行本地算法、导出透明 PNG、无保存关闭源文件，再恢复批处理前的活动文档。单张失败不会影响后续图片；失败占位文件会被清理。报告只记录相对路径并脱敏宿主错误。

## 本地算法适用范围

最适合：透明 PNG、纯色/近纯色背景、硬边图标、游戏/UI 素材、高对比商品图。

需要精修或视觉模型：场景/渐变背景、主体与背景颜色高度接近、发丝、玻璃/烟雾等半透明材质、同色语义细节。纯 RGB 信息不足时，本地算法会以 `non-uniform-background-border`、`ambiguous-foreground-background` 或相关风险失败关闭，不会承诺任何图片都自动抠净。

## 可选 AI 视觉模型

默认预览包未配置 AI，也不会上传图层。可信集成方配置视觉模型后，面板才会启用该选项，并在发送图层像素和 Trimap 前要求用户确认。API 支持返回 Alpha，或 Alpha 加修正前景 RGB；本地边缘参数仍只在插件内执行一次。

## 安全与故障反馈

- “撤销”丢弃插件内未应用结果，不修改 Photoshop 图层。
- 计算结果使用请求版本保护，过期异步结果不会覆盖新结果。
- 应用失败时保留工作区状态，便于继续修正或重新尝试。
- 若 Photoshop 菜单出现两个插件入口，说明旧实例仍在加载；Stop、移除旧实例并从新目录重新 Add/Load。
- 真实宿主故障请保留完整状态栏文字、Photoshop 版本、操作步骤和截图；不要只截“失败”二字。
