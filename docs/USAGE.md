# 使用说明

![0.2 面板预览](../assets/ui-preview-0.2.png)

## 快速开始

1. 在 Photoshop 中选择像素图层并点击“读取”。
2. 点击“一键抠图”。
3. 在 Photoshop 画布或插件面板中检查蒙版结果。
4. 在默认展开的“手动精修”区选择保留、删除或未知区域；圆形画笔出现后按住鼠标涂抹。
5. 使用缩放滑杆、加减按钮或直接滚动鼠标滚轮，在 5%–800% 间缩放预览图，也可点击“适合窗口”。
6. 调整边缘偏移、羽化和硬边阈值，点击“根据标记重新计算”。参数变更后旧预览不能直接应用。
7. 确认结果后点击主操作区中的“应用蒙版到图层”。

## 批量抠图

1. 在 Photoshop 图层面板中多选需要处理的像素图层。
2. 点击“批量抠图所选图层”；插件会使用本地算法逐层生成并应用蒙版。
3. 文字、组、智能对象等非像素图层会跳过；单层失败不会阻止后续图层。点击“停止批量”后，当前层安全完成并停止后续图层。
4. 批量期间不要切换文档、修改图层多选或改变图层边界；检测到变化后插件会停止写入。

如果点击“读取”或“一键抠图”后没有状态变化，请先在 UXP Developer Tool 中 Stop/Load 重新加载当前 manifest；插件加载完成后底部会显示“插件已加载”。如果旧包显示静态界面但仍不响应，请重新解压当前 Release 包后再 Add Plugin，旧包的入口脚本路径无法被 UXP 正确解析。面板浮动时可拖拽窗口边缘自由调整大小，内容会随窗口伸缩，过窄或过矮时仅内部滚动。

默认流程完全离线。临时预览不会修改原始像素，但会暂时替换当前用户蒙版并在正常取消时恢复；Photoshop 临时预览不可用时会改用面板预览，仍可应用正式蒙版。开发预览若遇 Photoshop/UXP 异常退出，请先使用 Photoshop 撤销检查原蒙版。

计算中点击“取消计算”只终止任务并保留 Trimap 和参数。本地模式单张图层上限为 16,777,216 像素。

## AI 视觉模型

AI 模式不会默认启用。只有宿主注入完整的运行时 API 配置后，面板才会显示 AI 选项。启用前会显示目标主机、模型、超时和数据外发提示，用户必须确认后才发送图层像素、Trimap 和参数。远程端点必须使用 HTTPS，重试前需要再次确认可能产生费用。

## 已知限制

当前开发预览使用 fallback 算法验证工作流，不是生产级 matting 模型。复杂发丝、低对比度背景和半透明特效可能需要较多手动标记。原生 C++ 引擎和签名 `.ccx` 将在后续 Release 提供。
