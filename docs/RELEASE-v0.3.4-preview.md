# PS Offline Mask v0.3.4 Preview

## 修复内容

- 修复高饱和纯色背景上的深色同色投影被误判为不透明前景的问题。
- 修复封闭未知区和高距离分支绕过背景同色判定、把蓝边升级为 `KEEP` 的问题。
- JPEG 偏色边缘使用背景方向容差和全局可靠前景参照，减少蓝边、白边和阴影残留。
- 本地一键抠图默认边缘收缩改为 `-1 px`；用户仍可调整收缩/扩张和抗锯齿柔化。
- 新增逐图背景残留门槛：沿透明外部扫描背景残留，并单独检查封闭的不透明近背景色块、Alpha 总量、最大连通残片和近不透明污染；彩色背景上的近背景色残留触发硬失败，黑/白中性背景记录复核警告。处于测得背景色容差带内且达到面积门槛的封闭区仍按产品规则作为孔洞删除。
- 显著同色歧义不再静默猜测：本地一键抠图停止并要求进入精修或使用视觉模型 API。

## 离线验证

- 自动化测试 `242/242` 通过，语法检查、质量基准和预览包审计通过。
- 29 张本地练习图中，23 张算法适用图片逐图通过；3 张非一致边框图片明确判定为不适用；3 张同色歧义图要求精修或视觉 API。
- 壁炉等适用蓝底图在默认 `-1 px` 下通过。用户提供的人物蓝底图判为同色歧义，不再输出带蓝块的蒙版。
- `v0.3.3` 的平均残留指标已废弃：它漏掉近不透明背景残片，也可能用其他图片的好结果掩盖单张严重失败。

## 安全边界

本包仍是 UXP Developer Tool 预览包，不是签名 `.ccx`。本轮没有操作用户的 Photoshop。精修输入、真实蒙版写回、批量写回、Windows/macOS 安装、签名和公证仍需真实宿主验收。
