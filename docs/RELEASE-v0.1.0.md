# PS Offline Mask v0.1.0

首次公开 CCX 版本，面向 Photoshop 25.0+。

## 主要能力

- 本地优先处理透明图、棋盘格、纯色与近纯色背景。
- 改进绿幕/蓝幕内部孔洞、边缘残色和硬边 RGB 去污染。
- 提供透明、白、黑、灰与自定义背景预览，以及蒙版和前后对比视图。
- 支持边缘收缩/扩张、柔边、硬边、去色边和反相。
- 支持图层批量与文件夹批量，批量任务固定使用本地算法。
- 可选视觉模型只提供主体先验或 Alpha 候选；本地质量门仍决定是否允许写回。

## 安装说明

下载 `ps-offline-mask-0.1.0.ccx` 后可先尝试双击安装。该包尚未经过 Adobe Marketplace 签名；若 Creative Cloud 拒绝安装，请把 CCX 复制并改名为 ZIP，解压后使用 UXP Developer Tool 加载根目录的 `manifest.json`。

## 已知边界

- 主体与背景颜色高度接近、发丝、玻璃、烟雾和复杂场景背景可能需要精修或专业 Alpha 模型。
- 视觉大模型并不天然输出像素级 Alpha；只有服务端明确返回有效 Alpha/前景数据时才参与结果。
- 自动化测试与包结构审计不能替代真实 Photoshop、Creative Cloud 和不同操作系统上的安装回归。
