# PS Offline Mask v0.3.5 Preview

## 修复内容

- 精修窗口不再依赖几乎透明的事件捕获层，鼠标和 Pointer 输入改由实际可见的预览区域接收。
- 画笔光标覆盖层改用 Photoshop UXP 支持的显式四边定位，并禁止覆盖层截获输入，避免光标层被裁成零尺寸。
- `[` / `]` 快捷键同时直接绑定到获得焦点的画布框；UXP 未提供 `isTrusted` 字段时不再误报“未检测到输入”。
- 边缘收缩/扩张、抗锯齿柔化、硬边阈值和反相改为本地实时缩略图预览，不需要再次点击“一键抠图”。
- 实时边缘预览从不可变的基础 Alpha 重算，连续拖动使用防抖和最新版本优先，避免参数累积失真和旧计算覆盖新结果。
- 边缘实时预览不会重新调用完整抠图引擎，也不会重复请求视觉模型 API。

## 自动验证

- 252 项 Node 自动化测试通过。
- JavaScript 语法检查、发布树审计和版本一致性检查通过。
- 未操作用户的 Photoshop。真实 UXP 画笔输入、窗口交互和蒙版写回仍由用户安装本预览包后验收。

## 安全边界

本包仍是 UXP Developer Tool 预览包，不是签名 `.ccx`。最低宿主为 Photoshop 25.0；Windows/macOS 签名、公证和生产安装器不在本版本内。
