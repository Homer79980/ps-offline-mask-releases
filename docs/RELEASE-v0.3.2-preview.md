# PS Offline Mask v0.3.2 Preview

## 修复内容

- 使用用户提供的 `840×840` 水果总览原图完成离线回归。
- 删除樱桃梗之间由浅灰/纯白混色组成的封闭孔洞，并释放与边界连通的浅色残片，不再留下棋盘白块。
- 保留九个水果内部的高光、浅色纹理和深色细节。
- 本地纯色背景模式默认输出去背景污染后的前景 RGB 与 Alpha，解决深色背景上的烘焙白边。
- 单图与批量共用校正前景输出；从可靠一键结果进入精修时复用边界背景，无可靠背景的经典精修保持 `mask-only`。批量恢复原多选后继续下一层，原子回滚失败时立即停止。

## 验证

- 自动化测试：212 项全部通过。
- 图 2：识别一个 `1221 px` 的封闭混色孔洞；樱桃区域近背景色全不透明残点为 `0`，仅保留低 Alpha 抗锯齿过渡。
- 1024 x 1024 基准：孔洞 IoU `1.0`、孔洞泄漏 `0`；软边边缘 MAE `0.001310`、连续 Alpha 保留率 `100%`。
- 语法检查、发布审计与 ZIP 完整性校验通过。
- 未操作用户 Photoshop；真实 Photoshop 25+ 写回由用户安装后验证。

## 已知边界

纯 RGB 仍无法无歧义地区分同色小高光和小孔洞。本版继续优先保护小细节，误保留的小孔洞使用“删除”画笔修正。本包是 UXP Developer Tool 预览包，不是签名 `.ccx`。
