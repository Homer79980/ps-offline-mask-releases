# v0.2.3-preview

## 本轮修复

- 为 Photoshop 24.4 / UXP 7.0 增加专用透明输入层，不再依赖旧宿主尚未支持的 `pointer-events: none` 才能绘制。
- 同时监听 `pointer`、传统鼠标、`wheel`、`mousewheel` 和旧滚轮事件；重复事件会去重。
- 绘制、平移和预览高度拖动增加 document 级回退；鼠标松开、移出面板或窗口失焦会安全结束笔画。
- 未知、保留和删除工具显示半透明双圈画笔；`[` / `]` 可调整画笔大小。
- 增加柔软度。保留/删除笔刷写入 UNKNOWN 过渡外环和确定标签内核，实际参与 Alpha 重算；100% 柔软度仍保证至少一个确定标签像素。
- 增加“专注精修”模式，保留缩放、画笔、重算、重置和应用，并允许继续拖动调整预览高度。

## 验证

- 自动化测试：`99/99` 通过。
- JavaScript 语法检查：通过。
- 开发预览包安全审计：通过。
- 520×960 普通面板和专注精修布局静态验收：通过。
- 遵守用户要求，本轮没有由自动化流程操作 Photoshop；安装后请由用户完成滚轮、涂抹、快捷键、平移和应用的真机复测。

## 升级

1. 在 UXP Developer Tool 中 Stop 旧插件。
2. 下载并解压 `ps-offline-mask-0.2.3-uxp-preview.zip` 到新目录。
3. Add Plugin 并选择新目录中的 `manifest.json`。
4. Load 后确认面板标题显示 `v0.2.3 preview`。
5. 单选像素图层，将鼠标移入预览区，依次测试滚轮、三种画笔、`[` / `]`、柔软度、空格拖动和“应用蒙版到图层”。
