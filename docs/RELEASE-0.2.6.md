# v0.2.6-preview

## 本轮修复

- Photoshop 的插件菜单只注册“离线抠图”一个入口；“抠图精修”改为主面板按钮打开的大尺寸模态工作窗口。
- 保留主面板缩略图：读取后显示当前图层，计算后显示插件内蒙版结果。
- 精修画布支持鼠标位置滚轮缩放、空格加左键平移，以及未知/保留/删除三种可实际写入 Trimap 的画笔。
- `[` / `]` 可调节画笔直径；工具栏和半透明双圈光标旁的 `px` 数值实时更新。柔软度会生成真实 UNKNOWN 过渡带。
- “重新计算”更新精修结果；“应用蒙版”才写入 Photoshop；“取消”或关闭精修窗口恢复进入精修时的内存快照。
- 打开插件或切换单个像素图层时自动读取。切换发生在重算、应用或批处理期间时，会在当前操作结束后自动重查，不再残留旧图层信息或进入按钮全部失效的状态。
- 修复精修窗口关闭/重开、面板销毁和异步计算并发时的生命周期竞态。

## 升级与测试

1. 在 UXP Developer Tool 中 Stop 并移除所有旧版 `PS Offline Mask` 实例。
2. 下载并解压 `ps-offline-mask-0.2.6-uxp-preview.zip` 到新目录，不要覆盖正在加载的旧目录。
3. Add Plugin 并选择新目录中的 `manifest.json`，随后点击 Load。
4. 在 Photoshop 的插件菜单中确认 `PS Offline Mask` 下只有“离线抠图”一个入口。
5. 选择一个像素图层，确认面板自动读取并显示缩略图；点击“一键抠图”后确认缩略图显示蒙版结果。
6. 从主面板点击“打开抠图精修窗口”，依次测试滚轮缩放、空格拖动、三种画笔、`[` / `]`、柔软度、重新计算、取消和应用蒙版。
7. 在未应用的精修状态以及重算过程中切换到另一图层，确认旧信息被清除，新图层在操作结束后自动读取，按钮保持可用。
8. 多选像素图层运行批量抠图，确认逐层生成并应用蒙版。
