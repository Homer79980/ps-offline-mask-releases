# v0.3.1-preview 发布说明

这是面向 Photoshop 25.0+ 和 UXP Developer Tool 的开发预览包，不是签名 `.ccx`。

## 本版修复

- 修复一键抠图把彩色插画主体内部、高光和浅色纹理错误变成半透明的问题。
- 小面积封闭背景同色区域优先按主体高光保留；达到面积门槛的真实孔洞仍自动删除。
- 限制全局软阴影归一化只影响画布外部可达区域，避免主体内部不同明暗颜色互相污染 Alpha。
- 单图和批量抠图继续共用同一个算法入口。

## 自动化证据

- Node 测试：205/205 通过。
- 1024 x 1024 封闭孔洞 fixture：中位 188 ms，IoU 1.0，孔洞泄漏 0。
- 1024 x 1024 抗锯齿 fixture：中位 123 ms，边缘 MAE 0.001310，连续 Alpha 保留率 100%。
- 用户水果预览裁片离线回归：明显彩色像素中 Alpha 低于 240 的比例由 68.8% 降至 3.0%。
- 语法检查、发布审计、ZIP 路径检查和解压后逐文件 SHA-256 比对全部通过。

## 已知边界

纯 RGB 算法无法仅凭像素可靠区分“与背景完全同色的小高光”和“与背景完全同色的小孔洞”。本版优先保护小细节；若小孔洞被保留，请在抠图精修中选择“删除”画笔修正。

按用户要求，发布过程没有自动操作 Photoshop。真实 Photoshop 25+ 的精修输入、单层应用和批量写回仍由用户安装此包后验收。
