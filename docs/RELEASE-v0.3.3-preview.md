# PS Offline Mask v0.3.3 Preview

## 修复内容

- 新增“边缘收缩/扩张”和“抗锯齿柔化”的像素级数值显示；柔化提供关闭、1–4 px 五档。
- 柔化只在现有 Alpha 内部产生过渡，不再把完全透明的背景重新变成半透明白边。
- 前景 RGB 反解使用后处理前的可靠 Alpha；低透明边缘只从可信内侧颜色传播，避免白色或蓝色背景污染。
- 蓝色等高饱和背景上的同色系投影不再强制标成不透明前景，改由软 Alpha 求解。
- 边框不一致时标记 `non-uniform-background-border` 并拒绝本地纯色一键结果，避免复杂背景伪装成功。
- “抗锯齿柔化”和“硬边阈值”互斥，避免柔化后又被二值化。

## 离线验证

- 29 张用户练习素材：19 张强适配、4 张条件适配、3 张小目标/歧义、3 张复杂背景明确超出纯色算法范围。
- 29 张练习图代理输出的平均半透明边缘背景色残留由 `5.37%` 降至 `0.48%`。
- 壁炉蓝底样本由 `40.58%` 降至 `0%`；小书架由 `34.00%` 降至 `0%`；人物蓝底样本由 `30.69%` 降至 `0.21%`。
- 白底浅色水果样本由 `14.00%` 降至 `2.62%`。
- 推荐从默认 `0 px / 关闭` 开始；仍有细边时可试 `收缩 1 px + 柔化 1 px`。大于 1 px 的收缩可能损伤发梢、叶尖和细描边。
- 棋盘格边框、渐变海报和雪景的边框一致率门禁均触发，必须转精修或视觉模型 API。

## 安全边界

本包仍是 UXP Developer Tool 预览包，不是签名 `.ccx`。本轮没有操作用户 Photoshop；真实 Photoshop 25+ 的画笔、窗口、单图写回和批量写回仍由用户安装后验证。
