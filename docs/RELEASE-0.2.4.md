# v0.2.4-preview

## 本轮更新

- 将“离线抠图”快速操作和“抠图精修”编辑画布拆成两个 Photoshop 原生面板；精修面板可停靠、拖出浮动并自由调整尺寸。
- 主面板不再嵌入小预览；点击“打开抠图精修工作区”即可进入完整画布，自动唤起失败时也可从 Photoshop 插件菜单打开。
- 滚轮缩放会考虑居中画布、内边距和已有滚动量，围绕鼠标所在图像位置缩放；空格加左键拖动用于平移。
- 未知、保留和删除工具提供真实半透明双圈画笔，`[` / `]` 调整大小，柔软度写入 Trimap 过渡带。
- 精修使用独立编辑事务：应用只在最后写回一次，取消恢复进入前快照，关闭或隐藏面板不会丢失草稿。
- 精修进行时会锁定主面板的一键抠图、批量、刷新和快速确认，避免两个面板覆盖同一编辑状态。
- 补齐 Photoshop 24.4 / UXP 7.0 的模板开关、双形态面板根节点、再次显示后的新会话和 300ms 卸载生命周期兼容。
- 继续保留纯本地算法默认模式、批量抠图和可选 AI 视觉模型 API 接口。

## 升级与测试

1. 在 UXP Developer Tool 中 Stop 并移除旧插件。
2. 下载并解压 `ps-offline-mask-0.2.4-uxp-preview.zip` 到新目录，不要覆盖旧目录。
3. Add Plugin 并选择新目录中的 `manifest.json`，随后点击 Load。
4. 从 Photoshop 插件菜单打开“离线抠图”，确认标题显示 `v0.2.4 preview`。
5. 点击“打开抠图精修工作区”，或直接从插件菜单打开“抠图精修”。
6. 依次测试滚轮缩放、空格拖动、三种画笔、`[` / `]`、柔软度、重新计算、应用和取消。
