# PS Offline Mask 0.2.1 Preview

本版本补全可实际操作的单图精修和多图层批量流程。

## 新增与修复

- 预览图支持 5%–800% 缩放、滚轮缩放、加减按钮和适合窗口。
- 未知区域、保留、删除工具显示圆形画笔，第一笔不会再被临时预览取消流程吞掉。
- 原图与蒙版切换会显示对应的真实面板预览，不再用原图冒充不可用的蒙版预览。
- “应用蒙版到图层”移动到主操作区，生成有效预览后即可使用。
- Photoshop 图层面板多选像素图层后，可点击“批量抠图所选图层”逐层生成并应用蒙版。
- 批量支持停止、非像素层跳过、单层失败恢复、选择/文档/边界变化保护。
- 兼容 Photoshop 24.4 的 UXP 7.0：无需依赖较新版本的 ResizeObserver、pointer-events 或 pointer capture 才能拖动预览高度和绘画。

## 安装

下载并解压 `ps-offline-mask-0.2.1-uxp-preview.zip`，在 Adobe UXP Developer Tool 中选择解压目录根部的 `manifest.json`，然后点击 Load。升级旧版本时请先 Stop 旧实例，再加载新目录。

这是开发预览包，不是签名 `.ccx`。默认本地算法不上传图片；AI 视觉模型接口仍默认关闭且不包含任何凭据。

源码已通过 86 项自动化测试、JavaScript 语法检查和预览发布审计。未代替用户操作 Photoshop 做真实宿主验收，请按使用说明验证读取、画笔、缩放、应用和批量流程。
