# PS Offline Mask v0.4.0 Preview

## 主要变化

- 主面板改为紧凑短命令布局，并为缩略图增加放大入口。
- 放大预览和精修统一为单一的 Photoshop 风格工作台，不增加第二个插件菜单入口。
- 未知、保留、删除画笔直接绑定可见画布，支持滚轮缩放、空格平移、括号调整笔刷、柔软度、撤销/重做和手动重新计算。
- 边缘参数在主面板和工作台双向同步，并实时更新黑白蒙版与透明/白/黑/灰/自定义背景上的彩色抠图效果。
- 新增图层批量和文件夹批量的分离入口。文件夹批量支持 PNG/JPG/JPEG/WebP、递归、相对目录保留、透明 PNG、自动编号、停止、逐文件错误隔离和报告。
- 保留可选视觉模型 API v1/v2 契约；默认本地包不申请网络权限、不包含模型或密钥。
- 精修历史按操作顺序覆盖整笔绘制和边缘参数，Esc 可取消未完成笔迹，并区分“重置标记”和“重置全部”。
- 边缘滑杆一次拖动只产生一条历史记录；自动初稿与打开工作区时的快照分别保存。
- 大图边缘调整先发布最长边 1024 像素的交互预览，再以可取消任务结算全分辨率结果。
- 质量检查栏显示当前引擎、策略、置信度与边缘风险；常规显示栅格最长边限制为 2048 像素，原始分辨率仍用于计算和写回。

- 工作台画笔、快捷键、滚轮和平移在实际 UXP 模态窗口中的输入。
- 单图应用、图层批量和文件夹批量的真实 Photoshop 写回。
- Windows 与 macOS 的窗口行为、文件夹授权和安装流程。

本包是 UXP Developer Tool 预览包，不是签名 `.ccx`。
