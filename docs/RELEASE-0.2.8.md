# PS Offline Mask v0.2.8 Preview

本版集中修复 Photoshop 24.x 下精修绘制、单层应用和批量蒙版写入的宿主兼容问题。

## 主要修复

- 精修画笔改为独立的小尺寸透明 Canvas，圆环和实时 `px` 标签不再依赖 UXP 对复杂 DOM 光标的渲染。
- 绘制同时监听 Pointer 与传统鼠标事件，并对兼容事件去重；未知、保留、删除三种工具都能进入同一条连续笔画路径。
- 画笔视觉层在预览图范围内裁切，避免大笔刷靠近边缘时改变滚动范围。
- 正常关闭、取消、应用结算和面板销毁都会释放画笔画布和输入状态。
- Photoshop 24.4–24.7.x 写入前会唯一激活并验证目标图层，再按 Alpha 类型选择 `hideAll`、`revealAll` 或 `revealSelection`。
- 蒙版存在性查询失败时直接中止，避免把宿主错误当成“没有蒙版”；写入或校验失败时按快照恢复原蒙版、选区和图层多选。
- “背景”图层和完全锁定层会被明确拒绝或在批量中跳过，并显示转换/解锁提示，避免 `-32005`。
- 主面板切换到不支持的图层时会显示宿主返回的具体原因。

## 安装

1. 在 UXP Developer Tool 中 Stop 并移除旧版插件实例。
2. 下载 `ps-offline-mask-0.2.8-uxp-preview.zip` 并解压到一个新目录。
3. 在 UXP Developer Tool 中选择 Add Plugin，指向新目录根部的 `manifest.json`。
4. 点击 Load，在 Photoshop 的插件菜单中打开“离线抠图”。

不要直接覆盖 Photoshop 当前正在加载的旧目录，否则宿主可能继续运行旧 JavaScript。

## 图层要求

- 使用普通、未完全锁定的像素图层。
- “背景”图层请先双击转换为普通图层。
- 完全锁定的图层请先解锁。
- 批量时可多选多个普通像素图层；不可写入的图层会跳过并显示原因。
