# v0.2.2-preview

## 本轮修复

- 打开插件或切换到单个像素图层时自动读取；保留“刷新”按钮作为同层像素变化的兜底。
- 预览图支持无修饰键滚轮缩放，范围 `5%–800%`。
- 按住空格并用鼠标左键拖动，可平移放大后的预览图。
- Trimap 圆形画笔显示在预览画布上层，交互事件统一由预览容器接收，兼容最低 Photoshop 24.4 对应的 UXP 7.0。
- 未知、保留、删除三种工具可直接在原图预览中涂抹，第一笔立即写入 Trimap。
- 批量抠图通过 `hasUserMask` 明确判断普通图层是否已有用户蒙版，无蒙版图层不再在快照阶段失败。
- Photoshop 以成功 Promise 返回 action 错误时不再误判为回滚成功。
- 批量汇总会附带前 3 个失败图层的具体错误原因。

## 验证

- 自动化测试：`92/92` 通过。
- JavaScript 语法检查：通过。
- 开发预览包安全审计：通过。
- 本轮遵守用户要求，没有由自动化流程操作 Photoshop；按钮、画笔、滚轮、平移和批量流程需安装后由用户完成真机复测。

## 升级

1. 在 UXP Developer Tool 中 Stop 旧插件。
2. 下载并解压 `ps-offline-mask-0.2.2-uxp-preview.zip` 到新目录。
3. Add Plugin 并选择新目录中的 `manifest.json`。
4. Load 后打开 Photoshop 的“离线抠图”面板。
5. 单选一个像素图层，确认无需点击按钮即可显示图层名和预览。
