# v0.2.7-preview

## 本轮修复

- 修复 Photoshop 24.4–24.7.x “应用蒙版失败”：改用临时选区创建用户蒙版，避开旧宿主 `putLayerMask` 对大块零值 Alpha 的已知缺陷。
- 兼容写入放在单一 Photoshop 历史事务内；成功后恢复原选区和图层多选，失败时原子回滚原用户蒙版。
- 修复精修窗口只显示关闭按钮：优先使用 UXP 原生模态 API，明确设置默认、最小和最大尺寸，并移除旧宿主不兼容的 Grid/视口计算样式。
- 精修窗口默认 `1100×820`、最小 `640×480`、最大 `1600×1200`，支持从窗口边缘缩放。
- “应用蒙版”会先关闭精修窗口，再进入 Photoshop 写入，避免 Photoshop 24.4 的嵌套模态冲突；写入失败时保留精修内容。
- 批量处理现在保留 Photoshop 返回的描述符、错误代码和阶段信息，不再统一显示“未知错误”。
- 单层应用失败时恢复原蒙版后继续；如果恢复也失败，则立即停止批量，避免继续修改后续图层。

## 升级与测试

1. 在 UXP Developer Tool 中 Stop 并移除所有旧版 `PS Offline Mask` 实例。
2. 下载并解压 `ps-offline-mask-0.2.7-uxp-preview.zip` 到新目录，不要覆盖正在加载的旧目录。
3. Add Plugin 并选择新目录中的 `manifest.json`，随后点击 Load。
4. 在 Photoshop 的插件菜单中确认 `PS Offline Mask` 下只有“离线抠图”一个入口。
5. 选择一个像素图层，一键抠图后点击“应用蒙版”，确认图层蒙版创建成功。
6. 从主面板打开精修窗口，确认内容完整、边缘可缩放，并测试滚轮、空格拖动、三种画笔、`[` / `]`、重新计算和应用。
7. 给目标图层预先添加一个蒙版，再应用新结果；确认成功时蒙版被替换，失败时原蒙版仍在。
8. 多选三个像素图层运行批量抠图，确认逐层创建蒙版；如有失败，面板应显示具体阶段和错误代码。
